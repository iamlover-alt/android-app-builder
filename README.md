# Android App Builder

Design docs for a multi-agent system that turns an idea into a signed, tested, store-ready native Android app (Kotlin, Jetpack Compose).

- [docs/agent-architecture.md](docs/agent-architecture.md): the 20-agent core architecture, orchestration, security and roadmap.
- [docs/agent-catalog.md](docs/agent-catalog.md): the complete 94-role catalog in 8 layers, from foundation to product, plus governance and orchestration.

Figures and policy dates are as of 2026-10-30. Re-check Play policy pages before relying on them.

- [schemas/](schemas/): JSON Schemas for the typed handoff artifacts.
- [agents/](agents/): specs for the 8 Phase 1 agents.
- [docs/phase-1-build-plan.md](docs/phase-1-build-plan.md): build order for the core loop.
- [benchmark/](benchmark/): 10 starter app specs and run records.
- [docs/decisions/](docs/decisions/), [docs/failures.md](docs/failures.md), [docs/review-cadence.md](docs/review-cadence.md): the continuous-improvement loop.
