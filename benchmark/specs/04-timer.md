# Interval timer

**One-line idea:** Configurable work/rest intervals; keeps running in background.

**Stresses:** Foreground service, notifications

## Pass criteria
- Skeleton builds with no human edits (first-green-build).
- Every acceptance line in the generated PRD has a passing test.
- No crash or ANR on the device matrix (phone, tablet, dark mode, large font).
- Zero blocking accessibility findings.
